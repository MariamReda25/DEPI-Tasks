# Weather Application

Create a weather application that fetches weather data using AJAX. Display Data about the location and temperature using DOMManipulation.

[https://www.weatherapi.com/docs/](https://www.weatherapi.com/docs/)[http://api.weatherapi.com/v1/current.json?key={Your_Key}&q=](http://api.weatherapi.com/v1/current.json?key=%7BYour_Key%7D&q=){latitude,longitude}
Hint : Get Longitude and Latitude from Browser
